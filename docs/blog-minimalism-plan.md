# 블로그 미니멀리즘 디자인 개편 계획

- 작성일: 2026-09-24
- 작업 브랜치: `design/blog-refresh` (`main`에서 분기)
- 상태: 구현·로컬 검증 완료, 커밋·푸시·메인 병합 미실행
- 구현 기준: 원격 `main`의 신규 커밋 2개를 가져와 `e5eee68`까지 작업 브랜치에 fast-forward 반영

## 1. 목표와 범위

글 제목을 빠르게 훑고 본문을 편하게 읽을 수 있는, 여백과 타이포그래피 중심의 블로그로 정리한다. 흰 배경, 짙은 글자, 얇은 구분선으로 정보의 위계를 만든다.

대상은 글 목록 `blog/index.html`과 개별 글 `blog/*.html`이다. 홈페이지와 연결되는 이름·내비게이션·서체의 인상은 유지한다. 초기 블로그 개편에서는 홈페이지의 한국어·영어 화면을 유지했다. 이후 사용자 요청으로 공통 헤더·푸터·색상·서체 통일을 범위에 추가했다(10절).

글 내용, 주소, 날짜, 카테고리, 최신순 정렬은 유지한다. 검색, 다크 모드, 페이지네이션, 새 프레임워크 도입은 후속 과제로 둔다.

## 2. 현재 코드에서 확인한 점

| 현재 상태 | 개편 방향 |
| --- | --- |
| 공통 `body`에 파랑·주황 방사형 그라데이션 사용 | 블로그에 흰색 단색 배경 적용 |
| 헤더가 고정되고 반투명 배경과 블러 사용 | 문서 흐름 안의 간결한 헤더로 변경 |
| 목록은 이미 연도별 행 구조이며 제목 옆에 여러 태그 배지 표시 | 행 구조를 유지하고 제목·날짜 중심으로 정보 정돈 |
| 카테고리 필터는 파란색 알약 모양 버튼 | 텍스트 버튼과 밑줄로 선택 상태 표현 |
| 글 본문에 공통 `.card`의 배경·테두리·그림자 적용 | 본문 카드 장식을 제거하고 읽기 폭 제한 |
| 본문 문단과 목록이 보조 글자색 사용 | 본문을 짙게, 날짜 등 부가정보를 옅게 구분 |
| 카테고리 필터가 글 행만 숨김 | 필터 결과가 없는 연도 제목도 함께 숨김 |
| `build_blog.py`가 목록·본문 HTML과 필터 스크립트를 생성 | 생성 원본에서 변경 후 전체 글 재생성 |

위 표는 최초 계획 작성 시점의 소스 검토 결과다. 이후 원격의 홈페이지 미니멀 스타일 변경을 먼저 반영했다. 실제 구현은 최신 공통 스타일을 보존하고 블로그 전용 범위에서 진행했다.

## 4. 글 목록 구성

1. 상단은 `Wonjin Choi`와 `Home / Blog` 링크로 구성하고 현재 위치를 표시한다.
2. 중복된 `Writing` 표시는 덜어내고 `Research & Notes` 제목과 짧은 소개를 유지한다.
3. `전체 / AI / 경제 / 데이터분석 / 생각` 필터와 글 개수를 표시한다. 선택 상태는 굵기와 밑줄로 구분한다.
4. 연도별 최신순 목록을 유지한다. 데스크톱에서는 제목을 왼쪽, 날짜를 오른쪽에 배치한다.
5. 목록의 태그 배지는 제거하고 태그는 개별 글의 메타정보에 작은 텍스트로 옮긴다. 원본 태그 데이터는 유지한다.
6. 모바일에서는 제목 아래에 날짜를 배치한다. 제목은 말줄임 없이 표시하고 한글 단어 단위 줄바꿈과 긴 영문 줄바꿈을 함께 처리한다.
7. 필터를 선택하면 해당 글과 글이 남아 있는 연도만 표시한다. 필터 버튼은 여러 줄로 자연스럽게 배치한다.

구조 예시:

```text
Wonjin Choi                                 Home  Blog

Research & Notes
실험, 프로젝트 회고, 데이터 사이언스 인사이트를 기록합니다.

전체   AI (26)   경제 (15)   데이터분석 (14)   생각 (1)

2026
AI의 답이 합리적으로 보여도 따져봐야 한다        2026-08-17
─────────────────────────────────────────────────────
AI를 잘 쓰는 일은 자료를 더하고 빼는 일이다      2026-08-08
```

개수는 현재 예시이며 구현 시 기존처럼 글 데이터에서 계산한다.

## 5. 개별 글 구성

제목 → 날짜·카테고리·태그 → 본문 → 목록으로 돌아가는 링크 순서로 배치한다. 제목과 본문 사이의 충분한 여백으로 구분하고 본문을 감싸던 카드를 제거한다.

- 문단·소제목·목록·인용문의 간격을 정리하고 본문 링크에는 밑줄을 표시한다.
- 이미지와 차트는 본문 폭 안에서 비율을 유지한다.
- 넓은 표와 코드는 해당 영역에서 가로로 스크롤하고 페이지 전체는 넘치지 않게 한다.
- 기존 Tistory HTML과 TidyTuesday 글의 인라인 스타일·고정 너비를 확인한다. 필요한 경우 블로그 범위의 CSS나 생성 단계의 래퍼로 대응한다.
- 푸터는 저작권과 이름을 중심으로 간결하게 정리한다.

## 6. 파일별 변경 계획

| 파일 | 예정 작업 |
| --- | --- |
| `build_blog.py` | 목록·본문에 `.blog-page` 및 페이지 유형 클래스 추가, 본문 `.card` 제거, 메타정보·태그 배치 변경, 연도 그룹과 필터 처리 수정 |
| `styles.css` | `.blog-page` 범위의 색상 변수·배경·헤더·폭·타이포그래피·반응형 스타일 작성, 기존 블로그 규칙 정리 |
| `blog/index.html`, 생성되는 `blog/*.html` | 빌드 스크립트로 재생성하고 결과 확인 |
| `index.html`, `index-en.html` | 공유 CSS로 인한 시각적 회귀 확인 |

공유 `:root`, `.nav`, `.card`, `main`을 일괄 변경하지 않고 블로그 범위에서 조정한다. 생성된 HTML을 개별적으로 수정하지 않는다. 현재 블로그 필터는 생성 스크립트 안에 있으므로 해당 위치에서 수정한다.

## 7. 구현 순서와 검증

### 1단계 — 기준 화면 확보

- 로컬 서버에서 목록, 일반 글, Tistory 글, TidyTuesday 글의 현재 화면을 저장한다.
- `python3 .agents/skills/homepage-build/scripts/check_posts.py`로 원본 메타정보를 확인한다.
- 기존 경고와 글 URL 목록을 기록해 개편 후 비교한다.

### 2단계 — 목록과 공통 스타일

- 블로그 범위 클래스와 디자인 기본값을 적용한다.
- 헤더·소개·필터·연도별 목록을 정리한다.
- 필터의 `aria-pressed`, 내비게이션의 `aria-current`, 명확한 `:focus-visible`을 적용한다.
- 카테고리별 필터와 전체 복귀, 빈 연도 숨김을 확인한다.

### 3단계 — 본문 읽기 경험

- 본문 카드 제거, 폭·글자 크기·행간·메타정보 배치를 적용한다.
- 이미지·표·코드·인용문과 긴 제목을 실제 글에서 확인한다.
- 터치 영역은 필터·내비게이션 기준 높이 44px를 목표로 확보한다.

### 4단계 — 재생성과 최종 확인

```bash
python3 build_blog.py
python3 .agents/skills/homepage-build/scripts/check_posts.py --generated
git diff --check
```

- 375px, 768px, 1440px 화면에서 목록과 대표 글을 확인한다.
- 대표 글: `ai-work-and-human-judgment.html`, `tistory-204.html`, `tidytuesday-01-salmonid-mortality.html`.
- 키보드 이동, 링크 이동, 필터 선택, 200% 확대 상태를 확인한다.
- 한국어·영어 홈페이지를 전후 비교한다.
- 빌드 과정에 기존 날짜형 Tistory HTML 정리 로직이 있으므로 삭제 내역을 검토한다. 원본이 없는 HTML도 용도를 확인한다.
- 생성 결과의 변경 내역과 전후 화면을 함께 검토한 뒤 브랜치를 메인에 병합한다.

## 9. 구현 및 검증 기록

- 원격 반영: `c0e16e2`(홈페이지 내용·프로젝트 구성), `e5eee68`(홈페이지 미니멀 스타일). 작업 브랜치에서 fast-forward하여 새 커밋을 만들지 않았다.
- 구현: 흰 배경, 목록 880px·본문 720px 읽기 폭, 텍스트 필터, 본문으로 옮긴 태그, 본문 카드 제거, 모바일 날짜 배치, 목록 복귀 링크.
- 접근성: 본문 바로가기, 현재 메뉴 표시, 필터 선택 상태·결과 안내, 키보드 포커스, 표·코드의 키보드 스크롤.
- 생성 검증: 56개 글, 오류 0건. 기존 Tistory 카테고리 공란 39건·태그 공란 48건에 대한 경고 2개는 기존 상태로 유지했다. 삭제·고아 페이지 없음.
- 보존 확인: 전체 글의 본문 텍스트, 이미지 주소, 본문 링크, 목록 URL·정렬이 기존과 동일하다. 로컬 링크 대상이 모두 존재한다.
- 화면 검증: 로컬 Chrome에서 8개 페이지 × 3개 너비(375·768·1440px), 총 24개 조합 확인. 일반 글, Tistory HTML, 표·이미지 포함 글, TidyTuesday 글, 한국어·영어 홈페이지 포함.
- 동작 검증: 전체 및 4개 카테고리의 글 개수·숨김 상태·연도 그룹, 키보드 Tab 이동·Enter 선택, 200% CSS 확대 시 재배치 확인.
- 홈페이지 보존: 최신 원격 코드 기준으로 한국어·영어 홈페이지의 375·1440px 전후 스크린샷이 바이트 단위로 동일하다.
- 로컬 검토 자료: `/tmp/blog-refresh-review/`에 전후 PNG 및 검증 결과 JSON 저장. 임시 검증 도구는 저장소 밖에 둔다.
- 작업 상태: 디자인 브랜치의 미커밋 변경으로 남겼다. 메인 병합과 배포는 진행하지 않았다.


## 10. 홈페이지·블로그 공통 디자인 반영

후속 디자인 검토에 대한 사용자 요청으로 한국어·영어 홈페이지와 블로그의 공통 요소를 통일했다.

- 헤더·푸터는 공통 최대 폭 1200px와 동일한 좌우 여백을 사용한다. 홈페이지 콘텐츠 폭, 블로그 목록 880px·본문 720px는 유지한다.
- 모든 헤더는 일반 문서 흐름에 배치하고 로고 16px·굵기 600, 메뉴 14px, 최소 클릭 높이 44px, 현재 메뉴 밑줄을 공통 적용한다.
- 한국어 홈·블로그의 로고는 `최원진`, 영어 홈은 `Wonjin Choi`로 표시한다.
- 블로그에도 영문 홈페이지로 가는 EN 링크를 두어 메뉴 구성을 맞췄다. 언어 링크는 이동 대상을 접근성 이름으로 명시한다.
- 흰 배경, 본문·보조 글자·구분선색, 한글 대체 서체를 공통 변수로 통합하고 블로그의 중복 정의를 제거했다.
- 푸터 문구를 `© 2026 Wonjin Choi`로 통일하고 글자 크기 12px, 상하 여백 24px·32px를 공통 적용했다.
- 검증: 5개 페이지 × 4개 너비(320·375·768·1440px), 총 20개 조합에서 공통 헤더·푸터의 폭·여백·서체·배경 일치, 가로 넘침 없음, 콘텐츠 폭 유지 확인.
- 전체 카테고리 필터와 홈페이지 → 블로그 목록 → 글 → 영문 홈페이지 → 한국어 홈페이지 이동을 검증했다.
- 56개 글 생성 검증 오류 0건, 기존 메타정보 경고 2개 유지. `git diff --check` 통과.
